The purpose of this application:
- to learn full stack development (mainly backend)
- to make a clean apple reminders clone application

The stack is:
- Typescript, NextJS, tailwind
- Drizzle ORM, SQLite



Some things to note,
there are fundamental components that are used in apple reminders, and there are four main "filters" that are applied to these lists.

Today "filter"
- checks the lists and sees which items are due today and only displays them

All "filter"
- checks the items in all lists and displays them

Completed "filter"
- shows completed items

Scheduled "filter"
- shows any future items 



so the first fundamental component is called a 

list:
- this has a name/color/icon
- and this stores the next component called items

item:
- this is the actual to do item that the user can create
- it has text, date, and a simple integer tracker to check completion (0 or 1)
